# Provenance Archive

**Audience:** maintainers tracing original content and asset decisions. **Purpose:** retain useful evidence without treating old plans as current guides.

These documents are historical snapshots. Their old counts, prices, version claims and pending checks are not current product guidance. Canonical JSON owns current values. The archive remains in source and is excluded from installation ZIPs; Git history preserves deleted implementation plans and detailed development logs.

| [Initial Tavern](TAVERN_INITIAL.md) | Original serving/portion, drink and source/asset decisions |
